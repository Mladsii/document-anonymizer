# Анонимизатор документов

Небольшой FastAPI-сервис, который принимает TXT, DOCX и текстовые PDF, находит персональные данные и реквизиты и возвращает новый TXT с плейсхолдерами. Для распознавания русских имён и организаций используется Natasha; остальные типы данных обрабатываются правилами.

## Возможности

- Извлечение текста из TXT, DOCX и текстового PDF.
- Поиск ФИО и организаций с Natasha, а также телефонов, email, ссылок, адресов и реквизитов по шаблонам.
- Настраиваемый словарь замен в `config/rules.json`.
- Веб-страница и JSON/API-интерфейс на FastAPI.
- Исходный текст и карта замен не сохраняются приложением.

Сканированные PDF и текст внутри изображений не распознаются. Выходной файл содержит только текст: исходное оформление и метаданные не переносятся. Автоматическая анонимизация может пропустить данные или заменить обычные слова; проверяйте результат перед использованием.

## Запуск

Требуется Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8002
```

Откройте `http://127.0.0.1:8002`. Пример запроса:

```bash
curl -f -F file=@examples/test_anonimizator.txt \
  http://127.0.0.1:8002/api/anonymize -o anonymized.txt
```

Для тестов установите `requirements-dev.txt` и выполните `pytest`.
